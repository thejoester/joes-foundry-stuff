# Joe's Foundry Stuff

A personal FoundryVTT module containing Joe's collection of compendiums, macros, and quality-of-life scripts.

**Compatibility:** FoundryVTT v11–v13

---

## Features

### Combat Turn Timer
At the end of a turn / combat, sends chat message with time of turn/combat. Can add sarcastic messages for short or long turns. 

### Audio Auto Mix
GM-controlled world audio levels that are automatically applied to all connected clients. Sets per-sound playback volume on track start without touching individual player volume settings. When audio is started it will auto-adjust levels.

### Chat Archive
Auto-Archives all non-pinned chat messages to a log file, keeping your chat clean between sessions. Saves to a Journal that is kept for 30 days. 

### Image Overlay
Shows an image overlay to all connected players simultaneously. Supports configurable size, opacity, and blur. Useful for revealing maps, handouts, or dramatic moments, or even reminders. 

### Easy Scene Navigation

- Left-clicking a scene from the scene list will view it 
- Shift-clicking a scene from the scene list will preload the scene
- Alt-click a scene from the scene list will open scene configuration
- Adds icons in scene list for which players are viewing scene

### Misc thingys

- Suppresses annoying errors. Still show in log but supresses notifications
- Timer Macro, start a timer and show the countdown on the players screen. alarm sounds when finished. Supports multiple timers.
